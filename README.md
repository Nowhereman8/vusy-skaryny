# Вусы Скарыны — архіў, квіз і статыстыка

Праграма пра нечаканыя павароты беларускай гісторыі (Белсат History, 2022–2026, 121 даступны выпуск).
Плэйліст: https://www.youtube.com/playlist?list=PLCZLJLaNHoJKINbdRXyT6xr5KlVHKCNqW

## Структура

| Папка / файл | Што там |
|---|---|
| `transcripts/final/` | Канчатковыя транскрыпты, адзін файл на выпуск: `NNN_<youtube-id>.txt` |
| `transcripts/raw/scribe_v3/` | ElevenLabs Scribe v3 (з разметкай спікераў) — 001–035, 069, 110 |
| `transcripts/raw/gemini-3.5-flash/` | Gemini — астатнія выпускі |
| `data/catalog.txt` | Спіс выпускаў з плэйліста: пазіцыя \| id \| назва \| працягласць |
| `data/stats.csv` | Прагляды, лайкі, каментары, дата, працягласць па кожным выпуску |
| `data/comments_all.md` | Усе каментары гледачоў па выпусках (спачатку самыя залайканыя) |
| `scripts/` | Скрыпты: распазнаванне (Scribe, Gemini, Whisper) і збор статыстыкі |

Нумар `NNN` — пазіцыя ў плэйлісце (№1 — самы новы выпуск). Пазіцыя 027 — схаванае відэа, яго няма.
У `final/` для выпускаў, дзе ёсць Scribe, выкарыстаны Scribe (дакладнейшы), для астатніх — Gemini.
